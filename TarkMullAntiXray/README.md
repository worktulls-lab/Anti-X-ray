# TarkMullAntiXray 2.0

Детектор X-Ray для **Paper 26.2** (Java 25).

## Что делает и чего не делает

**Не делает:** не прячет руды. Это принципиально. Чтобы спрятать руду, её надо подменить в пакете чанка **до** отправки клиенту, а плагины туда не попадают — сюда пускает только само ядро сервера. Любой плагин может лишь досылать подмену после отправки, и между этими двумя моментами ксрей всё видит. Первая версия этого плагина так и работала, и именно поэтому не помогала.

**Делает:** считает статистику копки и ловит того, кто копает не по-человечески. Этого во встроенном анти-ксрее Paper нет вообще, и здесь плагин действительно на своём месте.

## Обязательный шаг: включить обфускацию Paper

Останови сервер, открой `config/paper-world-defaults.yml`, найди секцию `anticheat`:

```yaml
anticheat:
  anti-xray:
    enabled: true
    engine-mode: 2
    max-block-height: 64
    update-radius: 2
    lava-obscures: false
    use-permission: false
```

Запусти сервер и выполни `/antixray check` — плагин сам прочитает этот файл и скажет, включено или нет. Если выключено, он ещё и ругается в консоль при старте.

Правки при работающем сервере затираются при остановке — только на выключенном.

## Как считается счёт

```
счёт = (закрытые руды × вес руды) / пробито породы × 1000
```

«Закрытая» руда — та, у которой все шесть соседей непрозрачные, то есть увидеть её без чита было невозможно. Честная копка, включая шахты 1×2, даёт 5–20. X-Ray даёт сотни, потому что знаменатель у читера крошечный: он не копает породу, он идёт сразу к руде.

Блоки, поставленные самим игроком, в знаменатель не идут — иначе счёт занижался бы простой расстановкой камня.

## Команды

| Команда | Описание |
|---|---|
| `/antixray check` | Диагностика: что включено, следят ли за тобой, работает ли обфускация Paper |
| `/antixray stats [ник]` | Счёт, пик, пробито породы, найденные руды |
| `/antixray top` | Топ-10 по счёту |
| `/antixray reset [ник]` | Обнулить статистику |
| `/antixray alerts` | Вкл/выкл алерты лично для себя |
| `/antixray reload` | Перечитать конфиг |

Права: `antixray.admin` (op), `antixray.alerts` (op), `antixray.bypass` (никому по умолчанию, включая операторов).

## Проверка, что детектор живой

1. Зайди **обычным игроком в выживании** — в креативе и спектейторе плагин игнорирует по умолчанию.
2. Покопай камень минут пять.
3. `/antixray stats [свой ник]` — если «Породы пробито» растёт, всё работает.

Если пишет «Статистики пока нет» — смотри `/antixray check`: скорее всего мир исключён или ты в креативе.

## Тюнинг порога

Порог 45 — отправная точка, не истина. Неделю посмотри `/antixray top` на живом сервере и подгони под свою аудиторию: много ложных — поднимай, ловит поздно — опускай до 25–30.

Автобана нет намеренно. Счёт — это повод посмотреть логи и запись, а не приговор: игрок, зачистивший чужую шахту, тоже наберёт много закрытых руд при малом объёме породы.

## Сборка

Если файлы лежат в корне репозитория:

```bash
mvn -B -U clean package
```

Если внутри подпапки `TarkMullAntiXray` (как получилось при загрузке через браузер), в воркфлоу нужен флаг `-f`:

```yaml
run: mvn -B -U -f TarkMullAntiXray/pom.xml clean package
path: TarkMullAntiXray/target/TarkMullAntiXray-*.jar
```

Готовый файл: `TarkMullAntiXray-2.0.0.jar` → в `plugins/`.
